## Say what you want to end up with

The model cannot see your screen or your intent. State the goal, the audience and the format.

Instead of:

```text
Write about the new exam regulations.
```

Try:

```text
Write a 150-word notice to bachelor students about the new exam regulations.
Plain language, friendly tone, end with where to find the full text.
```

## Give the context you already have

Paste the relevant text or attach the file rather than describing it. Say what has been decided and what is still open.

```text
Here is the draft agenda (attached). Suggest a realistic time for each item.
Items 2 and 5 need the most discussion. The meeting is 90 minutes.
```

## Show the format

If you want a table, a list, JSON or a specific structure, ask for it or give a small example.

```text
Summarise each of these three articles as: Title, main claim, method, one limitation.
Use a table with one row per article.
```

## Break big tasks into steps

Ask for an outline first, agree on it, then ask for each part. You get better results and can steer along the way.

## Iterate in the same chat

The assistant remembers the conversation. Say what to change rather than starting over.

```text
Good. Make the second paragraph half as long and remove the bullet points.
```

## Ask for the reasoning

For decisions and analysis, ask the model to list assumptions and alternatives before it concludes. With a reasoning model, raise the effort in the assistant settings for hard problems. See [Models](/help/models#reasoning-effort).

## Put standing instructions in an assistant

If you begin every chat with the same explanation of your project, your tone or your terminology, create an assistant with those instructions and attach the documents it should know. See [Assistants](/help/assistants#create-an-assistant).

## Check the answer

Ask for sources and verify them. Ask the model what it is unsure about.

> [!WARNING]
>
> Never paste a citation, a number or a legal reference into your own work without checking the original.
